# Student Management System

## About the Project
A console-based Student Management System developed using Python and MySQL to manage student records.

## Technologies Used
- Python
- MySQL
- MySQL Connector
- VS Code

## Features
- Add Student
- View All Students
- Search Student by ID
- Update Student Details
- Delete Student
- Input Validation
- Database Error Handling

## Database
Database Name: student_management

Table Name: students

## Installation

1. Install Python and MySQL.
2. Install required packages:

```bash
py -m pip install -r requirements.txt
```

3. Create the database and students table in MySQL.
4. Create a `.env` file and configure your MySQL password.
5. Run the project:

```bash
py main.py
```

## Project Type
Python and MySQL CRUD Application.
